# Sobre este curso

O **Curso de Claude e Claude Code** é um projeto pessoal e independente,
criado e mantido por
[Nerdola Programador Jurídico](https://github.com/junior-aguiar-eng).

Não é um produto oficial da Anthropic, nem afiliado, endossado ou
patrocinado por ela. "Claude", "Claude Code" e nomes relacionados são
marcas da Anthropic, usadas aqui apenas para identificar as ferramentas
sobre as quais o curso ensina — como qualquer material educacional
independente sobre uma tecnologia de terceiros.

O curso nasceu da vontade de tornar o Claude e o Claude Code acessíveis
para quem nunca programou, sem depender de assinatura para aprender a
teoria: tudo roda gratuitamente no navegador, e o Claude Code entra só
como uma camada opcional de prática para quem já é assinante.
