# M0.4 — Ferramentas do Dia a Dia

*Bloco 0 — Panorama · Eixo A · Nível <NivelBadge nivel={1} /> puramente conceitual, sem lab*

## Abertura

Até aqui você entende o que é Claude e como escolher um modelo. Este
módulo apresenta o que dá para fazer além de só conversar em texto puro
— as ferramentas que tornam Claude útil para tarefas reais do dia a dia.

## Conceito central

Cinco ferramentas cobrem a maior parte do que você vai usar no dia a
dia. O foco aqui é o que cada uma faz e quando usar — como configurar
cada uma não é escopo deste módulo:
