# O que é código, e por que ele vira automação

:::tip Objetivo
Ao final desta lição, você vai entender o que é código e vai ter rodado
sua primeira instrução para o computador — sem instalar nada.
:::

## Por que isso importa

Toda vez que você faz algo repetitivo no computador — organizar arquivos,
responder mensagens parecidas, extrair informação de uma planilha — existe
uma chance de ensinar o computador a fazer isso por você. Isso é
automação, e é o motivo prático de aprender a escrever código: não é
sobre "virar programador", é sobre criar suas próprias ferramentas.

## O que é código

Código é um conjunto de instruções escritas numa linguagem que o
computador entende e segue à risca — diferente de uma pessoa, ele não
tenta adivinhar o que você quis dizer, ele faz exatamente o que está
escrito.

Uma das peças mais simples de código é a [variável](/glossario#variavel):
uma espécie de caixinha com um nome, que guarda um valor para você usar
depois. No exemplo que você vai rodar daqui a pouco, `nome` é uma
variável que guarda um texto.

## Pratique aqui

O quadro abaixo é um sandbox: um ambiente onde você roda Python de
verdade, direto nesta página, sem instalar nada e sem precisar de conta.
Troque o texto entre aspas na variável `nome` pelo seu nome e clique em
**Rodar**.

<SandboxPython code={`nome = "SEU NOME AQUI"
print(f"Olá, {nome}! Você acabou de rodar código de verdade.")`} />

Se aparecer uma mensagem de erro, tudo bem — errar faz parte de
programar. Leia a mensagem, ajuste o código e rode de novo.
