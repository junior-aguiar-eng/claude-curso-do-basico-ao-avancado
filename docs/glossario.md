# Glossário

Termos técnicos usados no curso, explicados em linguagem simples. Quando
um termo aparece pela primeira vez numa lição, ele vem com um link para a
entrada correspondente aqui.

## Código {#codigo}

Um conjunto de instruções escritas numa linguagem que o computador
entende e segue à risca — diferente de uma pessoa, ele não tenta
adivinhar o que você quis dizer, ele faz exatamente o que está escrito.

## Variável {#variavel}

Uma espécie de caixinha com um nome, que guarda um valor (um texto, um
número...) para o código usar depois.

## Sandbox {#sandbox}

Um ambiente isolado onde você pode rodar código de verdade sem instalar
nada e sem risco de afetar qualquer outra coisa no seu computador. Neste
curso, o sandbox roda direto no navegador.

## Claude Code {#claude-code}

Uma ferramenta de linha de comando que usa o Claude para ajudar a
escrever, entender e rodar código num ambiente de programação real. É a
camada opcional e mais avançada de prática deste curso — nunca é
obrigatória para entender ou concluir uma lição.
